# Pattern Analysis: @marcelopolitioficial (instagram)

Analyzed: 2026-07-18
Sample size: 3 contents
Period covered: 2026-07-16 to 2026-07-17

## Executive Summary

Politi é o perfil mais diretamente útil ao conselho-364: produz conteúdo diário de **gestão gastronômica** com estrutura de aula — tese provocativa no gancho, desenvolvimento com lógica de negócio, e CTA de engajamento/funil ("Comente DIAGNÓSTICO"). Suas teses centrais (processos > pessoas; cultura com comportamentos inegociáveis; operação que não depende do dono) são exatamente a pauta de um conselho executivo de restaurante. O perfil também mostra o modelo de negócio: conteúdo gratuito → comunidade paga (Food Club) → consultoria.

## Structural Patterns

- **Formato dominante:** Reels quase diários com caption longa em formato de artigo (300–500 palavras).
- **Estrutura da caption:** 1) afirmação contraintuitiva ou analogia ("Depender de um único craque é um risco"), 2) desenvolvimento com "porquê", 3) frases curtas em ritmo de martelo ("É o processo que define o padrão. É o processo que reduz erros."), 4) pergunta final aos comentários + palavra-chave de funil.
- **Hashtags fixas de nicho:** #gestaoderestaurante #donoderestaurante #restaurantelucrativo #negociogastronomico.
- **Colab com marcas próprias** (@politi.academy, @acelerafoodnation) para promover o ecossistema.

## Language Patterns

### Tone Profile
Mentor direto: fala "de dono para dono", usa "meu amigo", desafia o leitor, mas sempre com solução prática. Autoridade ancorada em experiência internacional (Hard Rock).

### Hook Patterns
1. Analogia inesperada: "Depender de um único craque é sempre um risco. Vale para o futebol, mas também para restaurantes."
2. Erro comum do líder: "Um dos maiores erros de um líder é abrir exceção para..."
3. Quebra de crença: "A maioria dos donos acredita que o desafio é administrar pessoas. Mas não é."

### Call-to-Action Patterns
1. Pergunta reflexiva nos comentários ("se seu gerente pedisse demissão amanhã...?")
2. Palavra-chave de funil ("Comente DIAGNÓSTICO")

## Recommendations for Squad

1. **Frameworks do Politi como pauta do conselho**: processos > pessoas, comportamentos inegociáveis, operação independente do dono — usar como critérios de avaliação do COO e RH nas pautas do Grupo 364.
2. **Estrutura de parecer**: a fórmula tese → porquê → ritmo de frases curtas → pergunta final é excelente template para os pareceres executivos do squad.
3. **Conteúdo educativo para o CMO**: se o Grupo 364 produzir conteúdo, o formato "aula de churrasco/gestão em reel com caption-artigo" é o padrão comprovado do nicho.
4. **Funil com palavra-chave**: mecânica "Comente X" é aplicável para captar leads de buffet/eventos e da linha de defumados.
5. **Ecossistema de marcas**: Politi mostra como perfis irmãos (@politi.academy) se reforçam — modelo para @364steakhouse / 364 Burguer / 364 Foodservices se marcarem mutuamente.
